AutojsPro API 服务

此服务模拟了AutojsPro的所有API接口功能，可以直接在浏览器中运行。

获取CSRF令牌

GET /csrfToken 
示例响应:
{
    "_csrf": "Tbs6hIVo--Ngb_G9VJ3lnoMR1EYRnQli5bEY"
}

获取配置信息

GET /api/v1/config 
示例响应:
{
    "wl": "0a4fd5d5accf385b8d5f382d7abcfea7"
}

文档重定向

GET /docs

重定向到官方文档: https://www.wuyunai.com/docs/v8/
